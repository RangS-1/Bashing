Installation Steps

  1. 1.
    Clone GitHub Repository: 
    git clone https://github.com/RangS-1/Bashing.git
  2. 2.
    Enter Project Directory: 
    cd Bashing
  3. 3.
    Give Execution Permissions to Scripts: 
    chmod +x *.sh
  4. 4.
    Run Your Selected Script: 
    ./sysmon.sh
    * For system scripts (like updater.sh / laravelarch.sh), run with sudo: 
    sudo ./updater.sh
